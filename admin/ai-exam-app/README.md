# AI Exam Admin App

โปรแกรมสร้างข้อสอบ AI ตัวหลักของ Admin Console

## เข้าใช้งาน

เปิด `/admin/ai-exam-app/` และเข้าสู่ระบบด้วยบัญชี Admin หรือ Teacher ที่มีสิทธิ์ AI Exam

## ส่วนประกอบ

- `index.php` หน้าโปรแกรมหลัก
- `app.php` แบบฟอร์มสร้างและตรวจข้อสอบ
- `app.js` การทำงานฝั่งเบราว์เซอร์
- `api.php` เชื่อม Gemini และสร้างคำถาม
- `settings-api.php` จัดเก็บ Gemini API Key แบบเข้ารหัส
- `exams-api.php` บันทึกข้อสอบลงคลังกลาง

โปรแกรมยังใช้การเชื่อมต่อฐานข้อมูล การเข้ารหัส API Key และระบบสิทธิ์จากโปรเจกต์ Next Beyond ชุดเดียวกัน เพื่อให้ข้อสอบที่สร้างปรากฏใน Admin และ Student Portal ได้ทันทีหลังเผยแพร่

## Prompt และการบันทึกข้อสอบ

- หน้าแบบฟอร์มสร้างได้ 2 ทาง: ใช้หัวข้อ/ระดับชั้น/คำอธิบายโดยไม่ต้องมีไฟล์ หรือใช้เอกสาร Google Drive เป็นแหล่งอ้างอิง
- โหมดสร้างจากหัวข้อเลือกความยากรวม หรือแบ่งจำนวนข้อเป็นง่าย/ปานกลาง/ยาก/ยากมากได้ และใช้ตัวอย่างที่ตรวจรูปแบบแล้วจาก `prompts/examples.json` ตามวิชาและช่วงชั้น ตัวอย่างเป็นแนวการเขียนเท่านั้น ไม่ใช่เนื้อหาบังคับ
- เมื่อเปิดโปรแกรมครั้งแรก `subject-prompts.php` ติดตั้ง Prompt สำหรับ 5 วิชาจาก `prompts/*.md` โดยเติมเฉพาะช่องว่างและรักษา Prompt/สถานะที่เคยปรับไว้ ใช้ตาราง `ai_exam_migrations` ป้องกันการเขียนทับเมื่อเปิดครั้งถัดไป
- แก้ Prompt ได้จากเมนู **จัดการ AI Prompt** ระดับชั้นในฟอร์มถูกส่งให้ AI และบันทึกกับชุดข้อสอบ
- โหมด `copy` รักษาลำดับแม้ส่ง shuffle มา ส่วน `similar` และ `levels` มีรอบตรวจทานเนื้อหาและเฉลยเพิ่มเติมก่อนตรวจรูปแบบข้อมูล
- การสร้างมากกว่า 10 ข้อจะแบ่งเป็นคำขอย่อยฝั่งเบราว์เซอร์ แล้วรวมและบันทึกเป็นข้อสอบชุดเดียว เพื่อลดปัญหา Web Server หมดเวลาระหว่างรอ AI
- ตรวจข้อความ ตัวเลือก เฉลย และคำอธิบายก่อนรับผล หากจำนวนข้อไม่ครบจะแสดงจำนวนจริงและคำเตือน
- หน้าเว็บบันทึกอัตโนมัติผ่าน `exams-api.php` ลง `exams` และ `exam_questions` ใน transaction เดียว ทั้ง `admin/tests` และ `admin/question-bank` อ่านข้อมูลชุดเดียวกันผ่าน API ร่วม ไม่ต้องนำเข้าซ้ำ
- ข้อสอบใหม่เป็น **ฉบับร่าง** ครูตรวจแก้ใน Question Bank แล้วเปิดให้นักเรียนทำจากหน้า Tests ได้
- หากบันทึกไม่สำเร็จจะแสดงปุ่มลองบันทึกใหม่ เก็บข้อสอบในหน้าปัจจุบัน และเตือนก่อนออกจากหน้า ใช้ `generation_request_id` ป้องกันการบันทึกซ้ำเมื่อคำตอบจากเซิร์ฟเวอร์ขาดหาย
- ต้องมีฐานข้อมูลตาม `database/exam_module.sql` และ Gemini API Key ที่ใช้งานได้ การตรวจโดย AI ช่วยลดข้อผิดพลาดแต่ยังควรให้ครูตรวจเนื้อหาก่อนเผยแพร่
- ฐานข้อมูลเดิมให้นำเข้า `database/ai_exam_update_20260913.sql` หนึ่งครั้ง ไฟล์สามารถนำเข้าซ้ำได้และไม่ลบข้อสอบเดิม

ตรวจรูปแบบข้อมูลด้วย `php tests/ai-exam-validation.php` จากรากโปรเจกต์ และสร้าง CSS ด้วย `npm run build:css` หลังปรับคลาส Tailwind

การรับผล Gemini ใช้ `responseMimeType` และ `responseSchema` ตาม [เอกสาร GenerateContent](https://ai.google.dev/api/generate-content#v1beta.GenerationConfig) เพื่อให้ได้โครงสร้างคำถามที่แน่นอน และรวมเฉพาะข้อความคำตอบจาก response parts
